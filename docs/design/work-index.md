# Work Index

PORT-303 replaces the `/work` route placeholder with the first complete editorial index in the Human Assembly system.

## Composition

- The page opens with a restrained index label, the route title, and the approved positioning statement.
- The three featured projects form an asymmetric `7 / 5 / centered 8` desktop sequence rather than an equal card grid.
- Below `lg`, the index becomes one deliberate reading column with no horizontal overflow.
- Each project uses one raised sheet with a project-specific, code-native artifact above its factual introduction.

## Artifact policy

- MEMX uses an original abstract configuration diagram. It is not a reconstructed interface and contains no exchange data.
- Domani uses a stylized planning-object composition built from approved product ideas. It is not presented as a screenshot.
- Iffer's Pictures uses an abstract crop-frame study to suggest photographic composition without standing in for approved project photography.
- Artifact geometry is decorative and hidden from assistive technology. Each case-study link references a registry-backed text equivalent for the visible artifact evidence.

## Interaction and accessibility

- Every entry is one real Next.js link with a visible project heading and destination-specific accessible name.
- Hover and focus affect the arrow and artifact without hiding content or relying on color alone.
- Active feedback uses a small transform and every primary link remains at least 44px tall.
- Entry reveals use opacity and transform only and are removed when reduced motion is requested.
- The complete page remains a Server Component and adds no client JavaScript or animation dependency.

## Deferred

- Approved project imagery belongs to the individual case-study tickets.
- Filter controls are excluded because three featured projects do not need filtering.
- Supporting PixelVerse and EarthCam context remains reserved for Home/About.
