# Homepage featured work

PORT-305 extends the homepage beyond the MEMX-led hero with a focused sequence for Domani and Iffer's Pictures.

## Scope and hierarchy

1. MEMX remains the first and most prominent project in the hero.
2. Domani follows as the independent product and mobile-engineering story.
3. Iffer's Pictures closes the sequence with complete creative and technical ownership.
4. The Work Index remains the route for comparing all three case studies.

The ticket does not add broader career narrative, supporting PixelVerse or EarthCam content, a contact section, or finished case-study pages.

## Composition

- The section reuses the registry-driven project sheets established by the Work Index rather than creating duplicate project facts or a competing visual language.
- Desktop offsets the two sheets across a 12-column grid so the sequence reads like assembled editorial plates instead of equal cards.
- Mobile collapses to one reading column with Domani before Iffer's Pictures.
- A restrained header and ruled footer make the section distinct from the hero while preserving the Human Assembly material system.

## Content and media safety

- Project names, roles, disciplines, summaries, routes, and artifact copy continue to come from `src/content/projects.ts`.
- Domani uses a faithful code-native composition rather than unverified analytics or roadmap claims.
- Iffer's Pictures uses the established abstract composition and does not introduce generated or unapproved photography.
- The section publishes no new metrics, external URLs, or private media.

## Interaction and performance

- The section is server rendered and adds no client JavaScript or dependency.
- Every project sheet remains a real case-study link with keyboard focus parity.
- The Work Index link includes hover, focus, active, and 44px touch behavior.
- Static registry content has no loading, empty, error, or success runtime state.
