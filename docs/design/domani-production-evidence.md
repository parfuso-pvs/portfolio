# PORT-503 - Domani production evidence

## Objective

Present Domani's defensible production snapshot as evidence with visible provenance and limitations,
without turning early traction into an unsupported growth or conversion story.

## Evidence structure

- Five metrics come directly from the typed Domani project record: active accounts, tasks created,
  identified monthly and weekly users, 30-day sessions, and verified lifetime transactions.
- Every metric retains its detail, source type, and `2026-08-26` snapshot date.
- The existing registry proof points provide supporting context for registration history, repeat
  planning, and retention proxies.
- No values are duplicated into the component or evidence-copy module.

## Visual system

- A dark ruled ledger presents metrics as accountable records rather than generic dashboard cards.
- Values use the technical numeric role while labels, details, provenance, and dates maintain a clear
  evidence hierarchy.
- A separate boundary column makes methodology limitations visible alongside the figures.
- Supporting behavioral signals return to the light editorial surface and ruled-row pattern.
- Desktop ledger rows use a fixed value column; mobile stacks each value above its explanation.

## Accuracy boundaries

- All figures are explicitly labelled as an August 26, 2026 snapshot.
- The project registry owns that snapshot date once; the section heading, boundary label, and metric provenance rows derive their display formats from it.
- Account totals exclude profiles recorded as deleted.
- Activity metrics refer to identified production users, not shared anonymous identifiers.
- Store evidence is limited to seven production-verified lifetime transactions.
- Revenue was not retrieved.
- No conversion rate is shown because lifetime-access profiles span different tracking eras.
- Shared Apple-family and Android identifier totals are not published.

## Interaction states

The evidence is static server-rendered content. Loading, empty, error, success, hover, focus,
disabled, and active states do not apply.

## Deferred

PORT-504 owns closing navigation and Domani's published status. Any additional approved production
evidence remains follow-up work.
