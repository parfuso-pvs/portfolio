# PORT-603 - Iffer's Pictures public-site proof

## Objective

Connect the Iffer's Pictures case study to its verified public result without reproducing the live
site as a fake browser mockup or introducing unsupported performance claims.

## Evidence boundary

- `https://ifferspictures.com` is stored once as the project's typed `publicUrl`.
- The URL returned HTTP 200 during implementation verification on August 28, 2026.
- The proof copy reuses the registry's existing ownership and proof-point language.
- The section makes no traffic, conversion, revenue, search-performance, or client-business claim.
- The live site remains the original public artifact; the portfolio does not reconstruct its UI.

## Composition

- A dark, gridded evidence surface states the project identity and Phil's approved ownership scope.
- A raised paper link overlaps the evidence surface like a documented public artifact rather than a
  generic call-to-action card.
- The URL is visible before interaction so the destination is transparent.
- Desktop uses an asymmetric twelve-column overlap; mobile returns the evidence and link to a clear
  single-column reading order.

## Interaction and accessibility

- The destination is a native external link with a minimum 44px target.
- Visible copy and the accessible label both disclose that the project opens in a new tab.
- Hover and keyboard focus lift the public-artifact sheet and move the directional mark; the active
  state returns it to the page plane.
- The directional SVG is decorative and hidden from assistive technology.
- The section is a Server Component. Loading, empty, error, success, and disabled states do not apply
  to this static public URL.

## Deferred

PORT-604 owns the shared closing navigation and the Iffer's Pictures `published` status. Additional
project media and production-performance claims remain out of scope.
